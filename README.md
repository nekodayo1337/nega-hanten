# ネガ反転

8mm などのカラーネガをスキャンした動画を、ブラウザの中でふつうの色（ポジ）に直すページです。

## 使い方

1. ページを Chrome か Safari で開く
2. 動画（MP4・MOV）をドラッグ＆ドロップする
3. 左右に並んだ「元の動画」と「直したあと」を見て、「この色で書き出す」を押す
4. 終わったら「保存する」を押す（ダウンロードのフォルダに `元の名前_反転_補正.mp4` で入ります）

動画はパソコンの中だけで処理します。どこにもアップロードされません。

## 何をしているか

- 左右（や上下）の黒い帯の幅を自動で見つけ、帯は黒のまま残す
- 帯の内側だけを反転し、赤・緑・青をそれぞれ動画全体の明るさの範囲（0.5%〜99.5%）に合わせて伸ばす
- 仕上げとして、赤と青の暗いほうを少し締める（`worker.js` の `LOOK`）
- 映像は H.264 で書き出し、音声（AAC）はそのまま写す

色の計算は ffmpeg の `negate` と `colorlevels` と同じ式を BT.709 で行います。

## 動くブラウザ

WebCodecs が使えるブラウザ（Chrome・Edge・Safari 16.4 以降など）。
